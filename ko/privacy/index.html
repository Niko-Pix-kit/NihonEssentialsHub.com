사이트 운영자

본 사이트는 일본 후쿠오카의 Nihon Essentials Hub G.K. (Nihon Essentials Hub 合同会社)가 운영합니다.

사이트 이용

본 사이트는 정보 제공용 웹사이트입니다. 광고 쿠키, 문의 양식, 제3자 미디어 삽입 기능을 사용하지 않습니다. 호스팅 제공업체는 사이트 제공 및 보안을 위해 기술적 연결 데이터를 처리할 수 있습니다.

Google Analytics

동의한 경우 Google Analytics는 페이지 조회 등 사이트 이용을 측정합니다. Google은 기술적 연결 정보와 브라우저 데이터를 받습니다. _ga 및 _ga_LHR5R3H8ZP 쿠키는 브라우저를 구분하고 최대 180일 동안 세션 상태를 유지합니다. Nihon Essentials Hub은 페이지 조회 설정에서 URL 쿼리와 프래그먼트를 제외하고, 참조 URL을 오리진으로 제한하며, 사이트 태그에서 광고 기능을 비활성화합니다.

이메일 문의

이메일 링크는 사용자의 이메일 앱을 엽니다. 문의하시면 제공하신 정보를 답변 및 문의 관리에 사용합니다.

외부 웹사이트

Amazon과 pix-kit 링크는 별도의 웹사이트로 연결됩니다. 각 운영자의 개인정보 처리방침과 약관이 적용됩니다.

브랜드와 창작물

BAMBOOM과 pix-kit은 Nihon Essentials Hub의 브랜드입니다. 별도의 합의가 없는 한, 독립 창작물의 권리는 각 작가와 개발자에게 있습니다. 다른 회사의 브랜드명과 제품명은 해당 권리자에게 귀속됩니다.

언어 및 쿠키 선택

자동 언어 선택은 위치 서비스에 접속하지 않고 브라우저 언어를 사용합니다. 언어별 URL과 탭 세션 환경설정이 페이지 이동 중에도 명시적인 선택을 유지합니다. 영구적인 언어 쿠키는 환경설정을 허용한 경우에만 설정됩니다. 필수 쿠키는 허용 또는 거부 선택을 6개월 동안 기억합니다. 페이지 하단의 ‘환경설정 관리’에서 선택을 변경할 수 있습니다.
